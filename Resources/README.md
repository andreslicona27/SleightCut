# SleightCut app icon

`AppIcon.png` is the original image generated with the built-in image_gen tool. `AppIcon.icns` contains the macOS icon sizes, generated by `scripts/build-icon.sh`. The app build copies the ICNS into its Resources directory before signing.

## Final generation prompt

Use case: logo-brand. Asset type: production macOS app icon for SleightCut, a premium video editor for magician Thibault Di Maria. Create ONE polished square icon, 1024x1024, straight-on orthographic view, no mockup. A near-black rounded-square macOS icon tile with generous transparent padding outside the tile. Center a bold crimson ace-of-spades silhouette with a clean warm-white play triangle cutout in its broad upper body, subtly suggesting magic and film. A single offset burgundy playing-card outline behind the spade adds a restrained sense of sleight of hand. Sophisticated minimal sculpted materials, softly beveled edges, restrained red rim lighting, excellent silhouette and contrast at 32 pixels. Palette near-black #010101, burgundy #0E0505, crimson #DB2B33, deep red #9B1E22, warm white #FCF3F2. Broad simple geometry, centered balanced composition, tile occupies about 86% of canvas. No text, letters, watermark, extra symbols, tiny details or scenery. Actual transparent background outside the rounded tile.
